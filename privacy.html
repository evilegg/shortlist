Privacy Policy

Last updated: March 2025

Short version: Shortlist is self-hosted software. All data stays on the server the operator controls. No data is collected by, transmitted to, or stored by the Shortlist project or its maintainers.

What Shortlist is

Shortlist is open-source, self-hosted software. Each deployment is operated independently by a Discord server administrator (the "operator"). The Shortlist project and its maintainers do not operate any shared instance of the bot and have no access to any operator's data.

Data the bot collects

When running in a Discord server, Shortlist observes messages in registered channels and records the following data locally on the operator's server:

  • Discord user IDs and usernames of members who post YouTube links
  • Discord user IDs and usernames of members who react to those links
  • YouTube video URLs posted in watched channels
  • Emoji reaction events (which user reacted with which emoji to which message)
  • Computed scores derived from the above reactions

This data is stored in plain-text files (JSONL format) on the operator's own server. It is not transmitted to any external service except the YouTube Data API (see below) and Discord's own API (required for normal bot operation).

YouTube Data API use

Operators may optionally connect a YouTube account to allow Shortlist to create and manage playlists on their behalf. When this feature is enabled, Shortlist calls the YouTube Data API v3 to:

  • Create a new YouTube playlist on the operator's account
  • Insert ranked videos into that playlist

End users (Discord server members) never authenticate with Google. Only the operator authenticates, and only their YouTube account is accessed. See the API Use page for full details on OAuth scope usage.

Data retention and deletion

Because all data is stored locally by the operator, retention and deletion are entirely under the operator's control. To delete all collected data, the operator can remove the bot's data directory. The Shortlist project has no ability to delete data on behalf of any operator.

Data sharing

The Shortlist project does not sell, share, or transfer any user data to third parties. No analytics, telemetry, or crash-reporting systems are included in the software.

Discord

Shortlist operates as a Discord bot and therefore interacts with Discord's API. Discord's own privacy practices are governed by Discord's Privacy Policy.

Contact

Questions about this policy or about a specific deployment of Shortlist should be directed to the operator of that deployment. Questions about the Shortlist software project can be raised as a GitHub Issue.
