YouTube API Use

This page is written for Google API quota reviewers and describes exactly how Shortlist uses the YouTube Data API v3.

Summary: Shortlist uses one OAuth scope (https://www.googleapis.com/auth/youtube) to create playlists and insert videos on behalf of the server operator's YouTube account. End users (Discord server members) never authenticate with Google. All API calls are operator-initiated, not automated.

What Shortlist does

Shortlist is a Discord bot that collects YouTube links shared by members of a Discord server, scores them based on emoji reactions (👍 👎 ❤️ 🔥 💀 etc.), and optionally exports the highest-scored links as a ranked YouTube playlist.

The YouTube export feature is optional and operator-controlled. It is triggered manually by a server administrator running a Discord slash command (/drunktank admin-only export). The bot then calls the YouTube Data API to create a playlist and insert the ranked videos.

OAuth scope requested

Shortlist requests one OAuth scope:

  • https://www.googleapis.com/auth/youtube

This scope grants read and write access to the authenticated user's YouTube account. It is required because creating a playlist and inserting videos are write operations that cannot be performed with a narrower scope such as youtube.readonly or youtube.force-ssl alone.

Shortlist uses this scope only for the following two API operations:

  • Create a playlist — playlists.insert — creates a new playlist on the operator's YouTube channel with a title and description derived from the Discord channel being exported.
  • Insert videos into the playlist — playlistItems.insert — adds each ranked video to the playlist in score order, one API call per video.

No other YouTube API methods are called. Shortlist does not read, modify, or delete any YouTube content other than what it creates.

Who authenticates

Only the bot operator (the Discord server administrator who installed and configured Shortlist) authenticates with Google OAuth. This is a one-time setup step performed using a helper script (node scripts/get-youtube-token.js) that opens a browser authorization page, and the resulting refresh token is stored in the operator's own environment configuration.

End users — Discord server members who share links and react to videos — never authenticate with Google and never interact with any Google service through Shortlist. Their only interaction is through Discord's emoji reaction system.

Full user flow

  1. A Discord server member posts a YouTube link in a watched channel.
  2. Other members react to the message with emoji (👍, 👎, ❤️, 🔥, 💀, etc.).
  3. Shortlist records the link and reaction events locally on the operator's server. No YouTube API calls are made at this stage.
  4. When the operator runs /drunktank admin-only export, Shortlist reads the locally-stored scores, sorts the videos by score descending, and calls the YouTube Data API to:
    • Create a new playlist on the operator's YouTube account
    • Insert each video into the playlist in ranked order
  5. The operator receives a link to the newly created playlist in their Discord DMs.

API call volume

API calls are made only when the operator explicitly triggers an export. Exports are expected to occur at most weekly for a typical deployment. Each export makes:

  • 1 call to playlists.insert
  • 1 call to playlistItems.insert per video exported (typically 10–50 videos)

Estimated maximum: 51 API calls per export, with exports occurring at most once per week. There is no background polling, no scheduled API calls, and no rate-sensitive operations. The bot does not call the YouTube API at startup or on a recurring timer.

Data handling

The OAuth refresh token is stored in the operator's environment configuration (a .env file on their server) and is never transmitted to the Shortlist project or any third party. Access tokens are obtained from Google's token endpoint at export time and are used immediately; they are not persisted to disk.

Shortlist does not store, log, or transmit any YouTube account data beyond the playlist ID returned by playlists.insert, which is saved locally to allow the operator to update the same playlist on subsequent exports.

Compliance

Shortlist's YouTube API use complies with the YouTube API Services Terms of Service and the Google Privacy Policy. Operators are required to accept these terms as a condition of enabling the YouTube export feature (see Terms of Service).
